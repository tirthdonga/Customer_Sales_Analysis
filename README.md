# 📌 Overview

**Sales Data Analyzer** is a Microsoft Excel project created to analyze sales transactions and convert raw data into meaningful business insights.

The workbook contains four main worksheets:

- 📊 **Dashboard**
- 📈 **Analysis**
- 💡 **What-If**
- 📄 **Datas**

The project uses Excel formulas, Pivot Tables, Conditional Formatting, What-If Analysis, lookup functions, statistical analysis, and charts to analyze customers, products, regions, sales, and other business metrics.

---

# 🎯 Objective

The main objective of this project is to perform practical sales data analysis in Microsoft Excel and present the results through a professional dashboard.
